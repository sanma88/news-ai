🌐 1. Veille Technologie IA (Actu & tendances)

1. Z.ai lance GLM-5.4, un Loop Transformer de 750B paramètres avec vision

Z.ai a sorti GLM-5.4 le 23 novembre 2026, son premier modèle flagship basé sur une architecture Loop Transformer. 750 milliards de paramètres, 28 de ses 78 couches bouclées 2x par passe avant (+36% de profondeur sans paramètres supplémentaires). Vision ajoutée pour la première fois à la famille GLM. 1,5x le quota hebdomadaire vs GLM-5.3.

Sources: AI Weekly | Simon Willison

2. Anthropic publie une preuve Claude-auteur de VP ≠ VNP, non vérifiée

Papier de 70 pages "VP ≠ VNP over every field", modèle de recherche Claude interne comme auteur unique. Formalisation Lean 4 (324 fichiers), vérifications automatisées passées, mais aucun mathématicien humain n'a encore examiné le papier. Borne quasipolynomiale ~m^(c(log m)^(1/3)).

Sources: AI Weekly | explainx.ai

3. OpenAI + Cisco lancent Shirudo, bouclier eBPF contre les exploits Linux

Outil qui bloque les exploits Linux avec des boucliers eBPF temporaires au niveau du noyau, sans modification du noyau. Réponse directe aux menaces RCE sur les workloads d'inférence et d'agents IA.

Sources: AIToolsRecap | AI Weekly

4. Anthropic lance Claude Ship — agent de révision de pull requests

Agent d'ingénierie logicielle qui révise les PRs, corrige le code et peut les approuver. Opère directement dans le flux de développement, analyse les diffs, propose des corrections, prend des décisions d'approbation.

Sources: AIToolsRecap

5. Virginia et Oregon poursuivent SpaceX, X Corp. et xAI

Poursuite du 24 novembre 2026 concernant les générations d'images produites par Grok. Sorties du modèle d'image de xAI accusées de contenus problématiques ou non conformes aux régulations étatiques.

Sources: AIToolsRecap | explainx.ai

🔓 2. Veille Modèles Open Source & Open Weights

1. Inkling 2 Mini — Thinking Machines Lab, Apache 2.0, tourne sur un laptop

Modèle multimodal généraliste (texte + images → texte), Apache 2.0. Petit frère d'Inkling 2 Small. Ollama 0.40.17 (sorti vendredi 20 nov) le supporte sur Apple Silicon. Architecture à boucles (looped transformer), inférence locale.

Sources: AI Engineering Digest | Hugging Face

2. marvy-2-35B-MoE-GGUF — MoE 35B-A3B, Apache-2.0

Mixture-of-Experts 35B totaux / ~3B actifs par token. Fine-tuné pour le cycle de livraison ServiceNow. Quantisations GGUF pour llama.cpp, Ollama, LM Studio. Construit avec Qwen3.5 (Apache-2.0).

Source: Hugging Face

3. PrunedHub GPT-OSS-20B-28x — pruning 12,5% des experts MoE

Pruning sans perte de 12,5% des experts MoE (28 sur 32) de gpt-oss-20B. ~17,5B totaux, 3,6B actifs, 24 couches MoE, Top-4 routing, 128K contexte. Qualité nulle perdue.

Source: Hugging Face

4. DeepSeek-MoE-16B Q4_K_M — offload CPU, 11GB

Quantisation Q4_K_M (4-bit) de DeepSeek-MoE-16B avec offload CPU des experts MoE via Rust pour llama.cpp. 11 GB (depuis 31 GB F16). Apache 2.0.

Source: Hugging Face

Contrepartie à boucles variables : le nombre de boucles peut être choisi au moment de l'inférence (vs nombre fixe pour Inkling 2 Mini). Poids ouverts pour la recherche sur les modèles bouclés.
